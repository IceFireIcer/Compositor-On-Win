## 问题陈述（Problem Statement）

Compositor 是一款免费开源的图层式图像编辑器，围绕 Photoshop 式的合成与修图工作流设计，但它是 macOS 专属应用：要求 Apple Silicon、macOS 26 与 Xcode 26，其 Swift/SwiftUI/AppKit/Metal/CoreImage 技术栈在 Windows 上无法编译运行。Windows 用户的选择只有承担 Photoshop 的高额订阅，或忍受与自身工作流不契合的 GIMP/Krita。同时，基于 `.comp` 文件夹格式的 AI 代理自动化工作流（代理直接写 PNG 图层与 manifest、应用热重载）也只能在 macOS 上进行。

## 解决方案（Solution）

用 **Wails v2 + Svelte 5 + Go + WebGPU** 把 Compositor 重写为 Windows 原生桌面应用，目标**全功能对等**（对等清单以 [feature-parity.md](feature-parity.md) 矩阵为准，逐项验收）：

- **功能对等**：逐工具、逐菜单、逐面板复刻 macOS 版 1.4.5 的全部能力——15 个工具（16 含无工具态）、24 种混合模式（23 种 + Normal）、12 种调整图层、17 种滤镜入口、6 种图层特效、Camera Raw 全参数面板、内容感知填充/修复、PSD/PSB 导入、多标签项目、~114 条可重映射快捷键。
- **文件兼容**：`.comp` 项目格式（manifest v11）与 macOS 版双向兼容，跨平台互开；AI 代理契约（先写 PNG、原子改名 manifest、约 300ms 热重载）原样保留。
- **体验对齐**：Photoshop 式快捷键（Cmd→Ctrl 系统性映射）、常暗深色 UI、标签条、数值拖拽调节等微交互。
- **架构对位**：镜像原版「GPU 快路径 + CPU 真值」双轨——WGSL 管线负责屏上合成速度，Go CPU 合成负责导出真值与兜底，二者以黄金基准互证。

## 用户故事（User Stories）

> 编号与 [feature-parity.md](feature-parity.md) 矩阵的"故事#"列对应。

**文档与查看**

1. 作为 Windows 用户，我想打开 `.comp` 项目并在画布上看到与 macOS 版一致的合成结果，以便跨平台协作。
2. 作为用户，我想在单窗口内用标签页管理多个项目，关闭或退出时逐标签得到保存确认。
3. 作为用户，我想以 0.001×–32× 缩放（17 级键盘梯）并保持锚点稳定，用 Fit（⌘0）/实际像素（⌘1）/放大缩小，以便检查细节与整体。
4. 作为用户，我想用空格/中键/滚轮平移、⌘/Alt+滚轮缩放，以便操作与 Photoshop 一致。
5. 作为用户，我想在缩放 ≥800% 时看到像素网格（可开关），以便像素级编辑。
6. 作为用户，我想从标尺拖出参考线、使用可调间距与细分的布局网格（含网格设置表单），以便精确排版。
7. 作为用户，我想锁定/清除参考线，用总吸附开关与 Snap To（参考线/网格/图层/文档边界）逐项控制，以便精确对齐。
8. 作为用户，我想看到透明区域的棋盘格与文档边界，以便分辨画布内外。
9. 作为用户，我想通过欢迎屏新建指定尺寸与分辨率的画布，窗口尺寸被记住。
10. 作为用户，我想在状态栏看到缩放比与文档修改状态。

**图层面板**

11. 作为用户，我想控制图层可见性、不透明度，并从全部 24 种混合模式（含 Normal，Photoshop 原顺序）中选择，以便精确合成。
12. 作为用户，我想编组（⌘G）与取消编组（⇧⌘G）、嵌套至 64 层、移出文件夹，且组不透明度压暗其内部全部内容。
13. 作为用户，我想拖放重排/嵌套、⌥拖拽复制、内联重命名、上下移动（[ ]）、删除图层/蒙版/特效（菜单项随选中内容变化）。
14. 作为用户，我想为图层/组添加 8bit 灰度蒙版：绘制、填充、反相、羽化、越层绘制、链接/解链并独立变换蒙版，以便非破坏性隐藏。
15. 作为用户，我想创建/释放剪贴蒙版（⌥⌘G）并使用组蒙版。
16. 作为用户，我想复制/粘贴整层与文件夹（跨项目）、⌘J 经拷贝新建图层、⇧⌘N 新建空白层，并使用图层面板右键菜单。
17. 作为用户，我想合并图层（⌘E：向下合并/合并所选/合并组，菜单项随上下文变化标题）。

**绘制与修整**

18. 作为用户，我想使用带大小/硬度/不透明度/平滑的笔刷（B 绘制 / E 橡皮），按 Shift 画直线。
19. 作为用户，我想笔触即时跟手（4K 画布本地回显 <16ms）且抬笔后像素与预览逐位一致。
20. 作为用户，我想用仿制图章（对齐/不对齐、取样单层或全部、⌥点击设源）复制或修复区域。
21. 作为用户，我想用污点修复画笔的三种模式（内容感知/创建纹理/临近匹配）去除瑕疵。
22. 作为用户，我想用涂抹工具（R）的模糊/涂抹/液化三模式直接变形像素。
23. 作为用户，我想用渐变工具创建可再次编辑的渐变图层。
24. 作为用户，我想用形状工具画矩形（圆角）/椭圆/线，且保持可编辑而不被栅格化（Shift-U 切换）。
25. 作为用户，我想用吸管（I）取色并看到取样环（可开关），管理前景/背景双色板（含交换），并使用完整的 HSV 颜色选择器。

**选区与变换**

26. 作为用户，我想用矩形/椭圆选框与自由手/多边形套索创建选区。
27. 作为用户，我想用魔棒按容差选择（连续/全局、取样半径），并用对象选择点一下描出对象（Tab 切换两种模式）。
28. 作为用户，我想一键选择主体（⌥⌘A）与移除背景。
29. 作为用户，我想全选（⌘A）、取消（⌘D）、反向（⇧⌘I）、载入图层像素为选区、载入蒙版黑色区域为选区，以及按色彩范围选色（表单）。
30. 作为用户，我想对选区加减、移动选区框、移动/复制选区内像素、拖到边缘时自动滚动，选区轮廓以蚂蚁线呈现。
31. 作为用户，我想对选区扩展/收缩/羽化。
32. 作为用户，我想在有选区时用 ⌘T 变换选区框本身。
33. 作为用户，我想非破坏性地移动/缩放/旋转图层（缩小仍保留原始分辨率），并水平/垂直翻转图层或整幅画布。
34. 作为用户，我想 ⌘拖拽手柄自由扭曲、Shift 锁轴、多选层或整组一起变换，并可开关变换控件显示（⌘H）。
35. 作为用户，我想变换时有吸附与参考线提示、可输入精确数值、用方向键步进。
36. 作为用户，我想按 3:4、9:16 等比例裁剪、⌥ 对称裁剪、有选区时从选区开始。

**调整与滤镜**

37. 作为用户，我想使用 12 种调整图层（色相/饱和度、色阶含自动与三吸管、曲线、曝光、渐变映射、颗粒、添加杂色、高斯模糊、运动模糊、反相、黑白、色彩平衡），实时预览且随时可改。
38. 作为用户，我想从图像菜单直接对像素调整（曲线 ⌘M、色阶 ⌘L、色相/饱和度 ⌘U 等）并反相像素/蒙版（⌘I，选中蒙版时反相蒙版）。
39. 作为用户，我想使用 Camera Raw 滤镜全参数面板（光/色/曲线/混色器/颜色分级/细节/光学/几何/校准）与直方图、矢量示波器。
40. 作为用户，我想使用滤镜菜单：高斯模糊、运动模糊、添加杂色、晕影、辉光、抖动（11 种风格）、色调对比、镜头校正、Camera Raw、移除背景，预览限制在选区内。
41. 作为用户，我想给图层添加特效：描边、投影、颜色叠加、内阴影、外发光、内发光——GPU 渲染、随时可编辑。
42. 作为用户，我想用前景色（⌥⌫）/背景色（⌘⌫）填充、清除选区像素，并用内容感知填充（⇧⌫，可把图像延伸出画布边缘）。

**文本**

43. 作为用户，我想用文字工具创建可拖拽、可缩放的段落文本框并内联多行编辑（⌘回车提交、IME 正常）。
44. 作为用户，我想在工具头设置字体/字号/颜色/对齐/字距/行高，支持逐 run 字体与颜色混排。
45. 作为用户，我想变换文本并把文本用作剪贴蒙版。

**文件与导出**

46. 作为用户，我想导入 JPEG/PNG/HEIC/TIFF/SVG 与相机 RAW（先经 develop 步骤，读取 asShot 默认）。
47. 作为用户，我想导入 Photoshop PSD/PSB（8bit RGB）：保留可编辑的组、蒙版、混合模式、填充矩形/椭圆与水平文本，超大层裁剪到画布，应用前看到转换报告。
48. 作为用户，我想导出 PNG（⇧⌘E）与 JPEG（⇧⌥⌘S，实时预览）、使用"拷贝合并"（⇧⌘C）。
49. 作为用户，我想项目在后台保存期间继续编辑不被阻塞（原子保存）。
50. 作为用户，我想用画布尺寸（⌥⌘C）/图像尺寸（⌥⌘I）/修剪调整文档。
51. 作为用户，我想缩小时看到锐利的高质量降采样，大文档受内存预算保护。

**平台与代理**

## 实现决策（Implementation Decisions）

1. **技术栈**：Wails v2（稳定版）+ WebView2；Svelte 5 + Vite + TypeScript strict；Go 1.24+。理由与备选见 [ADR-0001](adr/0001-use-wails-svelte-go.md)。
2. **进程与真源**：Go 后端是文档唯一真源（模型/校验/历史/IO/像素）；前端持有视图状态（缩放/平移/工具/选区框 UI）与文档树只读镜像。前端不复制位图数据。
3. **双轨渲染**：屏上合成 = 前端 WebGPU/WGSL；导出真值与 GPU 不可用兜底 = Go CPU 合成器。两轨输出经一致性测试互证。见 [ADR-0004](adr/0004-webgpu-first-rendering.md)。
4. **像素内核**：9 个纯 C 内核（调整/色阶/魔棒/修复/填充/杂色/镜头/抖动/笔刷辅助）逐个移植为 Go 包（goroutine 并行）；C 原件作为算法真值保留在参考区，拷贝件进黄金基准 harness。见 [ADR-0003](adr/0003-pixel-kernels-ported-to-go.md)。
5. **混合模式行为**：24 种模式（含 Normal）全部在 **sRGB 空间**计算，逐模式复制原版的数值行为（含原版刻意偏离"线性光正确实现"的部分与 Photoshop 误差复刻）。
6. **文档模型**：扁平图层数组 + parentID 指针（底到顶），编组深度 ≤64、剪贴链 ≤256 节点；限制移植（边长 30,000px、单面 200M 像素、文档预算 min(800M, RAM/16) 像素）。
7. **撤销**：快照式 + 结构共享（不可变像素缓冲哈希寻址，未动层共享），100 条/256MB 修剪，嵌套事务，revision UUID 脏标记。
8. **`.comp` 兼容**：manifest v11 schema 逐字节兼容（排序键 pretty JSON）、校验规则逐条移植、原子保存；Windows 上跳过 QuickLook 预览目录的 Finder 语义。见 [ADR-0002](adr/0002-comp-format-compatibility.md)。
9. **IPC 契约**：Wails 类型化绑定命令（文档生命周期/编辑事务/工具操作/导入导出/设置）+ 事件推送（外部变更/进度/图层修订）；大块像素走 asset-server 本地 HTTP 端点直取 ImageBitmap，**禁止 base64 过 JSON 桥**。
10. **笔刷延迟策略**：笔触在前端本地缓冲、WGSL 覆盖层即时呈现，抬笔才把瓦片补丁提交给 Go（256px 瓦片模型与原版一致）；光标/蚂蚁线等覆盖层独立于合成循环。
11. **ML 能力**：主体选择/对象选择/移除背景用 ONNX Runtime + 开源分割模型（u2net/ISNet 系）替换 Apple Vision；引导滤波抠边（GuidedMatte）移植。见 [ADR-0005](adr/0005-vision-ml-replaced-by-onnx.md)。
12. **编解码**：PNG/JPEG/TIFF 用 Go 标准库；HEIC（libheif）与 RAW（LibRaw）经 cgo、vcpkg 管理；SVG 由前端光栅化；PSD/PSB 用移植的手写解析器。
13. **文本引擎**：Web 文本测量与光栅化 + Windows 字体目录枚举；IME 依赖 WebView2 原生支持；PSD 文本 run 往返。
14. **分发与更新**：NSIS 安装包；自动更新走 GitHub Releases + EdDSA 签名 feed（替代 Sparkle）；CI 为 GitHub Actions windows-latest。
15. **仓库布局**：`reference/Swift/` 只读；Go 后端 `internal/{domain,project,history,pixel,render,psd,importer,exporter,bridge}`；前端 `frontend/src/lib/{gpu,canvas,state,bridge,shortcuts}` + 组件目录。

## 测试决策（Testing Decisions）

> 详见 [testing.md](testing.md)。原则：只测外部行为（manifest 字节、渲染输出 PNG、交互后的文档状态），不测内部实现。

- **缝合点（从高到低）**：
  1. **ProjectStore 往返**（最高缝合点）：任意文档 → 保存 → 重开 → 逐字节 manifest 等价 + 逐像素等价（对应原版 ProjectTests）。
  2. **文档 API**：经公开文档接口驱动工具/变换/调整，断言文档状态（517 个 Swift 测试的语义移植：图层/历史/笔刷/选区/调整/相机原始族）。
  3. **黄金基准**：Windows 原生编译原版 C 内核 → 参考 PNG；Go 内核输出逐位一致（或规定 ε）。
  4. **CPU↔GPU 一致性**：同一文档分别经 Go 合成与 WGSL 合成，输出对比。
  5. **前端单元**：视口数学（缩放梯/锚点/吸附）与状态机用 Vitest。
  6. **E2E 冒烟**：Playwright 走 Wails dev server（对应原版 2 个 XCUITest 流程）。
- **先例**：原版测试语义 + 黄金 PNG 即先例；CI 全绿阻塞合并。

## 范围之外（Out of Scope）

- 修复 macOS 版自身的缺陷（reference 区只读不动）。
- iOS/iPadOS/Linux/网页版（Wails 选型天然限定桌面，未来另议）。
- 原版没有的能力：16bit/CMYK、Display P3/ColorSync 色彩管理、Darker/Lighter Color 混合模式（原版明确省略）、手写笔压感。
- 云同步/协作编辑、插件系统。
- Windows 资源管理器缩略图处理器（shell extension）——以包内缩略图替代，M9 复评。
