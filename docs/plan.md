# Compositor for Windows — 执行路线图（M0–M10）

> 决策依据见 [adr/](adr/) · 架构见 [architecture.md](architecture.md) · 测试见 [testing.md](testing.md)
> 状态：☐ 未开始 · ◐ 进行中 · ☑ 完成 · 更新日期：2026-10-05

## 总原则

- **对等审计**：[feature-parity.md](feature-parity.md) 是唯一权威功能清单（工具 T / 菜单命令 C / 调整 A / Camera Raw R / 特效 E / 图层 L / 选区 S / 文本 X / 文件 I / 视图 V / 平台 P 十一组，150+ 行）。拆票时逐行核对"里程碑"列，验收时逐行勾"状态"列——任何功能不允许游离在矩阵之外。
- **Tracer bullet**：每个里程碑结束时应用必须可运行、可演示——不存在"中间不可用的 半成品"状态。
- **兼容性优先**：从 M1 起任何时刻的 `.comp` 读写都必须与 macOS 版互开；这是合并进 main 的硬门槛。
- **黄金基准驱动移植**：C 内核的 Go 移植以"参考 PNG 通过"为完成定义，不以"看起来对"为准。
- **真值先行**：每个 GPU 特性都先有 Go CPU 版真值，再做 WGSL 版对齐。
- 每个里程碑经 `/to-tickets` 拆票后逐票 `/implement`（TDD）+ `/code-review`。

## M0 脚手架 ☐

**目标**：Windows 上 `wails dev` 可跑、CI 绿、编辑器外壳就位。

工作项：
1. Wails v2 项目初始化：`main.go`、`wails.json`、Go module；前端 Vite + Svelte 5 + TS strict。
2. 暗色主题外壳：工具栏、标签条（空态）、左侧工具栏（15 个工具占位）、状态栏、图层面板容器。
3. GitHub Actions：windows-latest 上 lint + `go test` + vitest + `wails build`。
4. NSIS 安装包构建走通（先不签名）。

**出口标准**：应用在 Windows 构建并运行；前端热重载可用；CI 全绿；空文档可新建。
**依赖**：无。

## M1 文档核心（Go）☐

**目标**：Go 侧成为 `.comp` 的完整真源——读写、校验、撤销、外部变更监视。

工作项：
1. `domain`：文档/图层/变换/蒙版/调整/特效/形状/文本样式/参考线模型；DocumentLimits 限额移植。
2. `project`：manifest v11 完整读写 + 校验规则逐条移植（路径安全、尺寸/数量/层级上限、混合模式拼写表、逐版本特性门控）+ 原子保存 + PNG 资产管理。
3. `history`：快照撤销（不可变像素缓冲结构共享、100 条/256MB 修剪、嵌套事务、revision 脏标记）。
4. 监视：fsnotify 300ms 合并、原子重命名后重挂、sha256 digest 比对、外部变更原位重载（保留视口与选区、脏文档先询问）。
5. 测试：ProjectTests / LayerTests / HistoryTests / ExternalChangeTests 语义移植；用 macOS 1.4.5 真实 `.comp` 样例做互开验证。

**出口标准**：Go 测试全绿；本里程碑产生的 manifest 与 macOS 版保存的 manifest 双向可开；监视契约（写入 PNG → 原子改名 → ~300ms 重载）在测试中复现。
**依赖**：M0。

## M2 WebGPU 渲染管线 ☐

**目标**：复杂 `.comp` 以 60fps 忠实渲染——第一个可视化断层。

工作项：
1. `frontend/lib/gpu`：WebGPU 设备管理（探测 + 失败回退声明）、纹理缓存（LRU + 内存压力响应）、Lanczos mip 链。
2. WGSL：24 种混合模式（sRGB 空间语义，逐模式对齐原版数值）；6 种图层特效通道（覆盖率/行-列分离模糊/环形合成）；调整应用（1024 项 LUT + 33³ color cube，与 GPU 导出一致性思路对齐）。
3. `render`（Go CPU）：全文档合成器（导出真值 + 兜底）；CPU 版混合模式与特效；统一光栅工厂（8bit RGBA 预乘 sRGB）。
4. 合成规则：蒙版（图层/组/剪贴）、组不透明度衰减、变换重采样（Nearest/Smooth/High quality）、文档边界与棋盘格。
5. 测试：CPU↔GPU 一致性测试族；黄金 PNG（无 GPU 依赖的合成正确性）；GPUCanvasTests / TiledLayerTests / DownsampleTests 语义移植。

**出口标准**：含蒙版/编组/特效/调整的复杂 `.comp` 在 60fps 渲染；同一文档 CPU 与 GPU 输出一致；导出真值可用（M5/M7 依赖它）。
**依赖**：M1。

## M3 画布交互 ☐

**目标**：选区与变换工作流闭环，画布手感对齐原版。

工作项：
1. 视口移植（缩放梯 17 级、锚点保持、适配/100%、0.001–32×）；光标系统（合成徽标光标以 SVG/CSS 实现）。
2. 像素网格（≥800%）、标尺、参考线（拖拽创建/移动/删除）、布局网格、逐项吸附开关 + Ctrl 旁路。
3. 选区：矩形/椭圆选框、自由手/多边形套索、魔棒（`WandPixels.c` Go 移植：容差/连续/取样半径）、加减选、march ants 蚂蚁线（覆盖层动画）、选区拖动边缘自动滚动。
4. 选区命令族：全选/取消/反向、载入图层像素、载入蒙版黑色区域、变换选区（⌘T 选区态）、色彩范围（`color_range_mask` 移植 + 表单）。
5. 对象选择交互骨架（点选 → 蒙版，M6 接 ONNX 真实现）。
6. 变换：移动/缩放/旋转/翻转（图层级与画布级）/自由扭曲（⌘ 拖拽、Shift 锁轴、多选与整组、精确数值、方向键步进、⌘H 变换控件开关、吸附提示）。
7. 裁剪（比例/对称/选区起点）；选区编辑（扩展/收缩/羽化/平滑）与选区剪贴板。
8. 吸管工具（取样环开关）+ 前景/背景双色板（含交换）+ 完整 HSV 颜色选择器表单。
9. 图层操作命令族：合并族（⌘E：向下/所选/组，菜单标题随上下文）、经拷贝新建（⌘J）、新建空白层（⇧⌘N）、创建/释放剪贴蒙版（⌥⌘G）、编组/取消编组/移出组、参考线锁定（⌥;）与清除。
10. 基础表单控件：数值拖拽调节（原版 NumericScrub 语义：拖标签 scrub）、点击定位、方向键步进——所有工具头与表单复用。

**出口标准**：SelectionTests / SelectionEditsTests / TransformTests / CropTests / ResizeSnapTests 语义通过；选区→变换→裁剪工作流闭环；色彩范围、颜色选择器、合并图层族可用。
**依赖**：M2。

## M4 笔刷引擎 ☐

**目标**：绘制工具族对齐原版手感与性能（`docs/brush-performance.md` 为基准文档）。

工作项：
1. 笔刷模型移植：256px 瓦片、硬度/间距/平滑、不透明度累积、绘制/擦除模式、Shift 直线。
2. WGSL 笔刷覆盖核：高斯-勒让德积分沉淀、永久/临时尾双缓冲（对齐 `MetalBrushCoverage`）。
3. 延迟管线：本地笔触缓冲 → 覆盖层即时呈现 → 抬笔提交瓦片补丁 → 撤销集成；右键拖拽调笔刷 HUD。
4. 其余绘制工具：橡皮、仿制图章（对齐开关、单层/全层取样）、模糊/涂抹/液化（`MetalWarp` → WGSL：逐 dab 纹理原位变形 + 偏移场）、渐变、形状；填充命令（前景色 ⌥⌫ / 背景色 ⌘⌫、清除选区像素）。
5. 测试：BrushTests / BrushIntersectionTests / CloneStampTests / SpotHealing 骨架 / GradientTests / ShapeToolTests 语义通过；4K 画布回显 <16ms 基准。

**出口标准**：绘制族测试全绿；4K 基准回显 <16ms；笔触提交后像素与预览逐位一致。
**依赖**：M2。

## M5 调整与滤镜 ☐

**目标**：非破坏调整体系 + Camera Raw 全量对齐。

工作项：
1. 12 种调整图层：色阶（含自动+三吸管）、曲线、色相/饱和度（33³ cube）、曝光、渐变映射、颗粒、黑白、色彩平衡、反相、高斯/运动模糊、杂色——内核逐个移植 + LUT/cube 应用；同一组表单同时提供图像菜单的破坏性调整入口（⌘M/⌘L/⌘U）与像素反相/蒙版反相（⌘I，选中蒙版时反相蒙版）。
2. 滤镜：高斯/运动模糊、添加杂色、晕影、辉光、色调对比、镜头校正（`LensPixels.c` 移植）。
3. Camera Raw 全量移植（`AdjustPixels.c` 的 `adjust_camera_raw*` 族，约 1,157 行——最大单点，按 光/色/曲线/混色器/分级/细节/光学/几何 分票）。
4. 实时预览管线：≤2048px 预览源 + 后台渲染 + 取消/替换 + 提交全尺寸；选区限制；直方图与矢量示波器。
5. 对应 UI：LevelsSheet / HueSaturationSheet / FilterSheet（含 Camera Raw 面板）。

**出口标准**：Camera Raw 输出与黄金基准一致；调整图层非破坏语义（HueSaturationTests / LevelsTests / CameraRawTests 语义）通过；预览管线取消替换无泄漏。
**依赖**：M2（合成）、M3（选区限制预览）。

## M6 内容感知与 AI ☐

**目标**：内容感知三件套 + ML 抠图对齐。

工作项：
1. 内容感知填充（`ContentFill.c` 移植）+ 画布外延伸。
2. 污点修复三模式（`HealPixels.c` 移植：最佳环匹配/纹理膜+颗粒/临近匹配）。
3. 抖动 11 风格（`DitherPixels.c` 移植）。
4. ONNX Runtime 集成 + 分割模型选型（u2net/ISNet 系，确认许可与体积）+ GuidedMatte 引导滤波移植 + 边缘偏移/对比精修。
5. 主体选择/对象选择/移除背景工作流接通（M3 骨架 → 真实现）。

**出口标准**：C 内核件与 C 黄金基准一致；ML 抠图质量对照原版效果评审通过；模型分发方案（内置/首启下载）与许可归档。
**依赖**：M3、M5。

## M7 文件进出 ☐

**目标**：格式大互通——PSD 导入 + 编解码矩阵。

工作项：
1. PSD/PSB 解析器移植（记录/通道 RLE+Zip、`levl`/`curv`/`hue2` 调整数据、文本 run、矢量填充/形状、超大层裁到画布）+ 转换报告 UI。
2. 导入：JPEG/PNG/TIFF（Go 标准库）、SVG（前端光栅化）、HEIC（libheif/cgo）。
3. RAW：LibRaw（cgo）解码 + develop 步骤 + RawDevelopSheet；asShot 默认值读取。
4. 导出：PNG/JPEG + JPEG 实时预览 + 拷贝合并；图像尺寸/画布尺寸/修剪表单。
5. 测试：Swift 测试套件的 PSD 内存夹具族（PSDFixture 生成的字节级 PSD）语义移植。

**出口标准**：PSD 夹具族导入正确（图层/蒙版/混合/调整/文本/矢量）；HEIC/RAW 打开可用；导出与原版逐位一致。
**依赖**：M1（文档）、M2（合成）。HEIC/RAW 可后置，不阻塞 M8。

## M8 文本工具 ☐

**目标**：文字系统对齐（原版为 TextKit，需 Web 引擎重写）。

工作项：
1. 段落文本框：拖拽/缩放框、内联多行编辑、IME（WebView2 原生）、⌘Enter 提交、Esc 取消。
2. 样式：字体/字号/颜色/对齐/字距/行高；逐 run 字体与颜色；Windows 字体目录枚举 + 字体名到 PSD 字体名映射。
3. 光栅化：文本 → 位图（保持样式对象可编辑）；文本作为剪贴蒙版、参与变换。
4. PSD 文本往返（`PSDText.swift` 682 行语义移植）。

**出口标准**：TypeToolTests 语义通过；中英混排与 IME 输入正常；PSD 文本 run 保留。
**依赖**：M2、M4。

## M9 平台集成 ☐

**目标**：像原生 Windows 应用一样安装、更新、被系统集成。

工作项：
1. 快捷键：~114 条定义表移植（Cmd→Ctrl 系统映射）+ 冲突校验 + 重映射 UI + 录制器控件。
2. 剪贴板/拖放：系统剪贴板位图进出、跨标签图层拖拽、文件拖放导入。
3. Shell 集成：`.comp` 文件关联、最近文件（跳转列表）、打开方式。
4. 分发：签名 NSIS 安装包；自动更新（GitHub Releases + EdDSA feed、静默/提示策略）；更新通道探测。
5. 代理契约端到端验证：外部进程写 `.comp` → 热重载提示 → 保留视口/选区。

**出口标准**：安装/卸载/升级走通；快捷键全覆盖且可重映射；代理契约在 Windows 实测通过。
**依赖**：M1–M8 的功能面（可按功能逐项合入）。

## M10 对等与打磨 ☐

**目标**：宣布功能对等。

工作项：
1. 性能与内存：DocumentLimits 预算实测、大文档（100M 像素级）、4K 笔刷基准、纹理缓存命中率。
2. 剩余测试移植收尾 + Playwright E2E 套件。
3. 与 macOS 版逐屏对齐的 UI 走查（对照原版截图/操作序列）。
4. 文档收尾：本 spec 的用户故事逐条勾验清单。

**出口标准**：spec 用户故事 50 条全部验收；两个平台对同一 `.comp` 的渲染一致。
**依赖**：全部。

## 风险登记

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| WGSL 与 Metal/CoreImage 数值差异（混合模式、特效、Camera Raw） | 渲染不一致、用户不信任 | 黄金基准逐模式验证；争议以 CPU 真值输出为准；sRGB 空间语义逐条复制 |
| Camera Raw（~1,157 行）与 PSB 解析器单点工程量 | 进度拖期 | 按参数族拆票；原版测试夹具作为验收；允许 M7 的 RAW/HEIC 后置 |
| WebView2 WebGPU 运行时差异 | 兼容性 | 启动特性探测 + Go CPU 兜底（导出路径本来就需要） |
| ONNX 模型许可/体积/质量 | M6 阻断 | 提前选型归档；备选：模型下载式分发或功能降级 |
| cgo 工具链（libheif/LibRaw/ONNX） | CI 复杂度 | vcpkg 固定版本；独立里程碑可裁剪不阻塞主线 |
| 文本引擎差异（TextKit ↔ Web） | M8 排版偏差 | 以原版 TypeToolTests 语义为准；PSD 往返夹具验收 |

## 拆票顺序建议（`/to-tickets` 输入）

1. M0 全部（4 票左右，无阻塞边）。
2. M1：`domain` → `project` → `history` → 监视（线性阻塞，每票以 Go 测试为出口）。
3. M2：`render`（CPU 真值）**先于** `gpu`（WGSL 对齐）——先有真值再对齐是硬顺序。
4. M3/M4 可在 M2 后并行拆票（选区族 / 笔刷族两条线）。
5. M5 按调整族分票，Camera Raw 单独成票簇；M6 依赖 M3/M5 完成后启动。
