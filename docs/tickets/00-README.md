# Compositor for Windows — 票目录索引

> 本地追踪器（`docs/tickets/`）。每张票 = 一张垂直切片（被实现者可独立演示/验收），带阻塞边。
> 实现规则：**frontier 优先**——任何"Blocked by"全部完成的票可以开工；每票 `/implement`（内部 TDD）+ `/code-review` 后勾选验收项。
> 对等矩阵行 = [feature-parity.md](../feature-parity.md) 中该票负责的功能行；验收时逐行勾"状态"列。**任何功能不得游离在矩阵与票集之外。**

**可立即开工（无阻塞）**：01（脚手架）、08（黄金基准 harness，仅依赖 reference 区 C 内核）。
