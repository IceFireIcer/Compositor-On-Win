# 01 — 脚手架与开发链路

**What to build:** 在仓库根目录建立可在 Windows 上运行、可热重载的 Wails v2 + Svelte 5 + TypeScript strict + Go 项目骨架，提供常暗深色主题的空编辑器窗口。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] `wails dev` 在 Windows 启动，前端改动热重载生效
- [ ] 深色主题外壳（背景/面板/工具栏色板）与空画布区域呈现
- [ ] Go 侧最小绑定往返可调用（前端调一个后端命令并显示结果）
- [ ] `go build` / `npm run build` 均通过；TS strict 无错误
- [ ] Wails 生成的前端绑定类型纳入版本控制

对等矩阵：基础设施（无直接功能行）；为 P06 铺路。
